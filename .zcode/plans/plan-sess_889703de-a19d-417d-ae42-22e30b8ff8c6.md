## Context

`/about` 使用共享的固定 Header。当前 Header 在手机端只减少了左右内边距，标题、主题切换、语言切换和 About 导航仍沿用桌面尺寸；在约 320px 宽度下这些元素会互相挤压或产生横向溢出。同时，移动端布局把正文起始位置设为 `40px`，小于固定 Header 实际占用的高度，内容可能被 Header 遮挡。

目标是在不改变桌面端视觉结构的前提下，让共享 Header 在窄屏上保持单行、稳定对齐、不横向溢出，并让正文和标题锚点避开固定 Header。

## 推荐实现

1. **整理 Header 的结构与可伸缩区域**
   - 修改 `components/Header/index.tsx`，把当前的内联字号样式拆成可复用的 CSS Module 类：标题链接、操作区（主题/语言）和导航分别有明确的 flex 角色。
   - 给标题区域设置可收缩能力，标题链接在极窄屏幕上使用单行省略，而不是撑破 Header；操作区和 About 导航保持不可压缩，避免按钮被挤变形。
   - 将 `components/Header/DarkModeSwitch.tsx` 的图片点击控件包在语义化的 `button` 中，补充可访问名称和足够的触摸区域；桌面端外观保持不变。

2. **重做 `components/Header/Header.module.css` 的响应式规则**
   - 保留桌面端现有的固定定位、颜色、字体和左右留白。
   - 增加统一的垂直居中、`min-width: 0` 和 flex 收缩规则，避免长标题或英文文案把整个 Header 撑宽。
   - 在 `max-width: 800px` 下将 Header 调整为约 `64px` 的紧凑高度，缩小标题字号、主题图标及其间距，缩小 About 字号和边距，并给语言按钮设置约 `32px` 的可点击区域。
   - 使用流式字号/间距和窄屏下更小的横向内边距，使中文、英文两种语言在 320px–800px 范围内都能稳定布局；移除依赖 `max-height` 的潜在裁切/溢出行为。

3. **同步固定 Header 的内容偏移**
   - 修改 `components/layout/layout.module.css`：移动端容器顶部偏移改为与紧凑 Header 高度一致（约 `64px`），避免 `/about` 正文首屏被固定 Header 覆盖。
   - 修改 `styles/post.css` 中标题的移动端 `scroll-margin-top`，让文章内锚点在手机端滚动后也不会被 Header 遮住；桌面端继续使用现有 `90px` 偏移。

## 验证

- 运行 `npm run lint`，检查 JSX/CSS 改动和新增 button 结构。
- 运行 `npm run build`，确认 Next.js 生产构建通过。
- 启动本地站点后分别以约 320px、375px、390px、768px 宽度检查 `/about`：标题、主题按钮、语言按钮和 About 链接不重叠、不出现横向滚动，正文首行不被 Header 遮挡；同时确认桌面宽度的 Header 外观未发生明显变化。
- 用 `curl`/浏览器访问构建后的 `/about`，确认页面仍返回成功状态。
